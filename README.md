# Eberechukwu Prosper Chibuike – Student Portfolio (COS 106)

Pages: index.html, about.html, projects.html, planner.html, contact.html
Folders: css/ (style.css), js/ (main.js, planner.js, contact.js), images/, media/

Open index.html in a browser to run locally. To host: upload the whole folder to
GitHub, then enable GitHub Pages (Settings > Pages > deploy from main branch / root).

## Replacing the placeholder pictures
Every placeholder is a normal JPG in the images/ folder. To use your own picture, save it
(JPG, ideally 800 x 600 px, 4:3) with the SAME file name and overwrite the placeholder:

- Home page: home-article-1.jpg ... home-article-5.jpg (main photo: david.jpg)
- About page: about-story.jpg, about-education.jpg, about-career.jpg,
  hobby-coding.jpg, hobby-reading.jpg, hobby-music.jpg, hobby-football.jpg
- Projects page: project1.svg, project2.svg, project3.svg (project screenshots)
If your picture is a .png, change the file name in the matching .html file too.
