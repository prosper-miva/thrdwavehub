Academic Planner

Add tasks, tick them off when done, or delete them

Staying organised is one of the biggest challenges for any student. I built this planner to help me keep track of assignments, revision, projects and deadlines in one simple place. Use it to plan your own study tasks too.

Total: 0 Completed: 0 Pending: 0

    How to Use the Planner

    1. Add a task. Type what you need to do, choose a priority (High, Medium or Low), optionally pick a due date, then press Add Task.
    2. Mark it completed. Tick the checkbox beside a task when you finish it. The task is crossed out and the counters update instantly.
    3. Delete a task. Press the Delete button to remove a task you no longer need.
    4. Filter your list. Use All, Pending or Completed to focus on what matters right now.

    Your tasks are saved in your browser, so they will still be there when you come back, as long as you use the same device and browser.

    Study Planning Tips

    Prioritise Wisely

    Handle high-priority and near-deadline tasks first. Urgent work done early removes stress and leaves time for quality.

    Break Big Tasks Down

    Instead of “Finish project”, add smaller steps such as “Design homepage” or “Test contact form”. Small wins build momentum.

    Review Daily

    Spend five minutes each morning checking your list. A quick review keeps you focused and prevents missed deadlines.

    How It Works

    The planner keeps all tasks in a JavaScript array of objects. Each time you add, complete or delete a task, the array is updated and the list on the page is redrawn using DOM manipulation. Event listeners respond to your clicks and form submissions, and the totals are recalculated automatically.
